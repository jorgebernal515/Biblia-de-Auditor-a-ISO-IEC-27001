# Biblia de Auditoría & Transición — Grupo 2 (ISO/IEC 27001 & 27002: 2013 ↔ 2022)
**Asignatura:** Auditoría de Sistemas · Programa de Ingeniería de Sistemas · UniSalamanca

## Propósito
Herramienta web estática de consulta rápida para el auditor que integra:
1. **Fichas ejecutivas de auditoría** sobre **ISO/IEC 27001:2022** (Cláusulas 4–10) e **ISO/IEC 27002:2022** (4 temáticas), incluyendo los **5 campos obligatorios** (Numeral, Objetivo, Evidencia, Prueba y Riesgo).
2. **Módulo de actualización normativa (2013 ↔ 2022):** búsqueda bidireccional por códigos 2013 o 2022, filtros de transición (*Nuevos 2022*, *Fusionados* y *Mantenidos*) y matriz comparativa rápida.
